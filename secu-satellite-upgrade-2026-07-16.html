Critical Pre-Checks
1

Hard removal — not deprecated. Hosts still running it silently stop receiving updates.
Action

Find every call to subscription-manager attach. Rewrite before 6.16.

What You'll Actually Use in 6.16

Key Screens
Content › Content Views
Content Views
Versioned snapshots of your patch content. You create a version, test it in Dev, promote to QA, then Production. Hosts only ever see what you've deliberately promoted — no accidental early push of a bad patch.
Hosts › All Hosts
Host Inventory + Errata
Every managed system in one view: applicable errata, installable packages, patch status, last check-in time, lifecycle environment. Replaces what you'd normally have to piece together from yum and subscription-manager separately.
Hosts › Compliance › Reports  NEW IN 6.16
OpenSCAP + Remediation Wizard
CIS Benchmark and STIG scans run on schedule, results per host as pass/fail percentages. Failing rules now have a built-in Remediation Wizard — generates and runs the fix playbook without leaving the UI.
Hosts › Remote Execution › Job Templates
Remote Execution Jobs
Run commands, scripts, and Ansible playbooks against any managed host without an agent installed. This is what replaces Katello-agent — dispatch jobs to a group of hosts, see live output per host, re-run failures.
