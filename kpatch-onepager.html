Why kpatch
Live. Always live.

Patches apply in-memory to the running kernel. SAP HANA, SAP NetWeaver, Oracle, and every other workload stays up through CVE remediation. No coordination with application teams. No rolling restart.

Patch on day one.

Traditional patching waits for the next scheduled maintenance window — weeks or months away. kpatch closes the CVE exposure gap on the same day Red Hat publishes the advisory. Critical severity patches often ship same day as the CVE.

Auditable by design.

kpatch list shows every active CVE fix and load status in real time. Patches are cumulative — each new release supersedes the last. Clean audit trail, always current.

How it works
1
Identify
Red Hat Insights or uname -r reveals your running kernel version. Insights flags exposed CVEs automatically.
2
Find the patch
kpatch-patch packages ship via Red Hat CDN or Red Hat Satellite — same delivery channel as all your existing RHEL content.
3
Install
One dnf install command. The patch loads into kernel memory on install — instantly. No reboot.
4
Verify
kpatch list confirms each CVE fix is active and loaded. Real-time status, no guessing.
5
Persist
kpatch.service re-applies all patches at next boot. Nothing to re-run manually after any future system restart.

At scale — delivering to your entire fleet
Red Hat Satellite

Satellite syncs kpatch-patch RPMs from the Red Hat CDN and organizes them into content views by environment — Dev, Stage, Production, SAP — so the right patch version reaches the right host group.

Patch applicability is tracked per host. Compliance gaps surface in the host dashboard. No manual repository management across distributed sites.

Red Hat Ansible Automation Platform

A single playbook using ansible.builtin.dnf pushes kpatch-patch RPMs to all nodes in parallel — targeted by host group, region, or workload type.

No SSH logins, full job history, zero manual intervention per host. Schedule execution for the same day Red Hat publishes a CVE fix.

Red Hat Insights

Insights continuously monitors CVE exposure across the fleet. When a critical CVE drops, Insights flags affected hosts immediately and identifies which kpatch-patch RPM closes the gap.

With Satellite and AAP in the pipeline, that remediation runs the same day — collapsing the exposure window from weeks to hours, with per-host proof of coverage.
