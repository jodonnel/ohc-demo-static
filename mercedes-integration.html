Mercedes-Benz Connected Vehicle Integration

Enterprise Edge-to-Cloud Architecture

● Red Hat OpenShift ● SAP Business Technology Platform ● Mercedes-Benz Developer APIs

Project Overview

This project demonstrates enterprise-grade integration of connected vehicle telemetry with SAP Business Technology Platform (BTP) using Red Hat OpenShift as the orchestration layer.

Built in collaboration with Red Hat and SAP, this reference architecture proves how modern enterprises can leverage vehicle data for asset management, predictive maintenance, and operational intelligence.

Business Context

SAP customers face two critical platform migrations by December 31, 2027:

  • SAP PI/PO (Process Integration) → SAP Integration Suite
  • SAP MII/ME (Manufacturing Integration) → SAP Digital Manufacturing

This creates an urgent need for proven edge-to-cloud patterns. Our Mercedes-Benz integration demonstrates how any connected asset — from luxury vehicles to industrial sensors — can flow through the same OpenShift → SAP BTP pipeline.

Technical Architecture

Mercedes-Benz Vehicle (VIN: W1NKM4HB0PU012482) ↓ OAuth2 (Vehicle Status 1.5 API) ↓ CloudEvents (fuel, odometer, location, diagnostics) ↓ Red Hat OpenShift (qr-demo-qa namespace) • Flask API (gunicorn, 2 pods, horizontal scaling) • Redis (pub/sub + persistence) • nginx (static assets + reverse proxy) ↓ SAP Business Technology Platform • SAP Event Mesh (CloudEvents ingestion) • SAP Integration Suite (EIC routing) • SAP S/4HANA (PM: Maintenance, EAM: Asset Management) • SAP SuccessFactors (Mileage tracking)

Technology Stack

Red Hat OpenShift 4.x Python 3.12 (Flask + gunicorn) Redis 7.x nginx (unprivileged) CloudEvents 1.0 Mercedes-Benz API Platform SAP BTP

Use Cases

Predictive Maintenance

Vehicle diagnostics → SAP PM work orders. Odometer + fault codes trigger maintenance scheduling before failures occur.

Fleet Asset Management

Real-time location + status → SAP EAM. Track high-value assets across distributed operations.

Expense Management

Mileage data → SAP SuccessFactors. Automated expense reporting for company vehicles.

Operational Intelligence

Fuel consumption patterns, utilization metrics, and location analytics for strategic planning.

Data Flow & Privacy

Authentication: OAuth2 authorization with Mercedes me account (vehicle owner consent required)

Data Sources:

  • Fuel level & range (read-only)
  • Odometer reading (read-only)
  • Lock status (read-only)
  • Tire pressure (read-only)
  • Location ping (coordinates redacted, only existence confirmed)
  • Battery voltage (read-only)

Privacy: No remote commands (lock/unlock/climate), no persistent location storage, coordinates redacted in event payloads.
