🎩 Chapeaux Rouge

A live event registration system — designed, built, and deployed
in a single session using the OHC edge-to-core pattern.

The pattern is the product.

In the OHC demo, south is a factory floor — scan guns, sensors, and edge devices capturing events in real time. North is the platform — Red Hat OpenShift ingesting, processing, and persisting that data. The closed loop is the operator acting on what the platform surfaces.

Chapeaux Rouge is the same architecture with a different workload. South is an attendee's phone. North is a managed OpenShift cluster. The closed loop is checking a badge at the door against a registration captured hours earlier. Same framework. Different skin.

The point isn't the speakeasy. The point is that this pattern took one working session to deploy — because the platform was already there. That's what Red Hat OpenShift does: it turns "we should build that" into "it's live."
