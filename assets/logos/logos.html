OHC Demo — Shared Logo Pool

Source: jodonnel.github.io/ohc-demo-static/assets/logos/  ·  Maintainer: Jim O'Donnell, Red Hat  ·  Last updated: 2026-02-28

One source of truth for logos across all OHC demos.
When a product is renamed or a logo changes (e.g. Insights → Lightspeed), update the file here. All demo pages that reference these URLs get the fix automatically.

Rule: Only logos actively in use belong here. Don't add logos speculatively. The full Red Hat brand asset kit lives locally at ~/brand-assets/ — never commit it to git.

How to add a new logo

1. Source the file from the Red Hat brand portal (AEM) or ~/brand-assets/
2. Copy to ~/ohc-demo-static/assets/logos/
3. Add a card to this page
4. Commit and push to GitHub (git push origin main from ~/ohc-demo-static)
5. Update Chloe MEMORY.md and CHANGELOG.md
6. Update any demo pages to reference the GitHub Pages URL (not a local path)
